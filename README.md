## Структура

Каждое задание лежит в отдельной папке со своим `README.md`:

```
chashchin_cv/
├── README.md
└── <папка задания>/
    ├── README.md        ← условие, решение, выводы
    ├── pyproject.toml   ← для консольных приложений (uv)
    ├── uv.lock
    └── ...
```

## Оформление

- Весь текст — отчёты, инструкции, описания — в Markdown.
- Консольные приложения оформлены проектами [uv](https://docs.astral.sh/uv/). Запуск:

  ```bash
  cd <папка задания>
  uv sync
  uv run <команда из README задания>
  ```
